# MineSteam 2.4.0

## Estabilidad + Instancias

MineSteam 2.4.0 consolida la base del launcher y reúne las mejoras desarrolladas durante las iteraciones anteriores en una única versión estable.

### Estabilidad
- Fabric, Forge y NeoForge.
- Gestión y detección de Java.
- Descargas con reintentos y verificación de archivos.
- Assets y reparación de archivos dañados.
- Idiomas vanilla disponibles dentro de las instancias.
- Reparación normal y reparación avanzada.
- Crash reports y diagnóstico.

### Instancias
- Configuración individual por instancia.
- RAM independiente, con máximo de 32 GB y puntos rápidos en 4, 8 y 16 GB.
- Java por instancia.
- Argumentos JVM personalizados.
- Backups completos y restauración.
- Backup preventivo antes de reparaciones.
- Logs por instancia.
- Servidor favorito por instancia.
- Perfiles y servidores funcionales.

### Modrinth y contenido
- Búsqueda de mods y modpacks por nombre.
- Filtros por Minecraft y loader.
- Selección de versiones.
- Favoritos.
- Instalación de mods y modpacks.
- Gestión de mundos, resource packs y shaders.

### Interfaz
- Diseño Steampunk + Minecraft Vanilla.
- Interfaz simplificada para nuevos usuarios.
- Sin biblioteca lateral ni gestor de descargas visible en el dashboard.
- Aprovechamiento completo del espacio horizontal.
- Barra lateral sin desplazamiento en escritorio.

## Desarrollo

```bash
npm install
npm start
```

### Windows

```bash
npm run build:win
```

### Prueba de arquitectura

```bash
npm run test:architecture
```
